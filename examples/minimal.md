# Introduction

This is the smallest document that exercises the pipeline. Build it with:

```
schriftsatz examples/minimal.md
```

Body text is justified and hyphenated. Paths such as `src/main/resources` in
code spans keep their slashes intact, while a path in running text like
some/long/path/that/would/otherwise/overflow/the/margin gains break
opportunities after each slash.
